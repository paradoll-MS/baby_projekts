# 香型分类与搜索策略 v2

## 整体流程

```
Excel读取
    │
    ▼
┌─────────────────────────────┐
│ ① 搜索前：排除无香/电子蜡烛    │  ← 只在这里做排除
│   unscented, LED, flameless  │     直接标记，不搜索
└─────────────────────────────┘
    │ （有香商品）
    ▼
┌─────────────────────────────┐
│ ② 在线搜索                   │  ← 所有有香的全搜
│   官网 → Amazon → 通用搜索     │
└─────────────────────────────┘
    │ （搜索到的文本 + 商品名文本）
    ▼
┌─────────────────────────────┐
│ ③ 文本清洗                   │  ← 从文本中去掉干扰词
│   品牌名 / wick材质 / 功能性词  │     然后才做关键词匹配
└─────────────────────────────┘
    │ （干净文本）
    ▼
┌─────────────────────────────┐
│ ④ 关键词提取 → 香族映射       │  ← 一级香族 + 二级香调
│   允许多标签                  │
└─────────────────────────────┘
    │
    ▼
  写入 Excel
```

## 一、① 搜索前排除（跳过，不搜索）

**只有这两类直接排除：**

| 类型 | 检测词 | 标记为 |
|------|--------|--------|
| 明确无香 | `unscented`, `fragrance[-]free`, `scent[-]free`, `non[-]scented` | 无香型 |
| 电子/LED | `flameless`, `battery[-]operated`, `led candle`, `fake candle`, `flickering flameless` | 无香型（电子） |

---

## 二、③ 文本清洗规则（搜索后、提取关键词前执行）

从搜索到的文本（+商品名）中**移除**以下内容，再做关键词匹配：

| 清洗类型 | 具体模式 | 说明 |
|----------|---------|------|
| **品牌名** | `WoodWick`, `Yankee Candle`, `Bath & Body Works`, `Capri Blue`, `Voluspa`, `NEST New York`, `Diptyque`, `Thymes`, `Chesapeake Bay`, `Stonebriar`, `LA JOLIE MUSE`, `M&SENSE`, `Sand + Fog`, `Salt & Stone`, `Sweet Water Decor`, `Village Candle`, `Glade`, `TIKI`, `Hosley`, `Lulu Candles`, `Maison Louis Marie`, `PHD CAKE` 等 | 品牌名≠香调 |
| **Wick 材质** | `wood wick`, `wooden wick`, `cotton wick`, `lead-free wick` | 烛芯≠香调 |
| **蜡基材质** | `soy wax`, `coconut wax`, `beeswax`, `paraffin wax`, `palm wax`, `natural wax` | 蜡基≠香调 |
| **功能性词** | `smokeless`(→smoke 误判), `dripless`, `long[-]burning`, `hand[-]poured`, `highly[-]scented`, `room[-]filling`, `non[-]toxic`, `clean[-]burning` | 功能≠香调 |
| **场景词** | `gifts for`, `birthday`, `christmas`, `wedding`, `holiday`, `mothers day`, `fathers day`, `valentines`, `anniversary`, `graduation`, `retirement` | 场景≠香调 |
| **规格词** | `pack of`, `count`, `oz`, `hour burn`, `wick` | 规格≠香调 |

> **核心原则**：品牌名、材质词、功能性描述只在「清洗阶段」处理——它们不影响是否搜索，只影响从搜索文本中提取关键词的准确性。

> **特别注意**：`smoke` 出现 22 次全部来自 `smokeless`→必须排除！
> `spa` 出现 15 次属于氛围词，不作为独立香调，但可以保留作为辅助信号。

### 二级：细粒度香调（即关键词本身）

一级分类后，命中的关键词本身即为二级标签。例如：
- 命中 `lavender`, `rose` → 一级=花香, 二级=[lavender, rose]
- 命中 `vanilla`, `caramel` → 一级=美食, 二级=[vanilla, caramel]
- 命中 `sandalwood`, `cedar` → 一级=木质, 二级=[sandalwood, cedar]

### 分类逻辑优先级

```
1. 先清洗（去掉品牌名、wick、功能性词）
2. 再匹配（用清洗后的文本匹配关键词表）
3. 大类收敛（单一大类归属）：
   a. 细分关键词 >= 8 个 → "混合 Mix"（通常为礼盒/套装）
   b. 否则按加权得分选最高大类：
      - 商品名自带关键词 2 分
      - 仅搜索来的关键词 1 分
   c. 丢弃非选中大类的关键词（不统计）
4. 二级香调 = 选中大类下的所有命中关键词
```

### Mix 混合香族

| 触发条件 | 大类 | 细分 |
|---------|------|------|
| 细分关键词数 >= 8 | 混合 Mix | 全部关键词保留 |

> 混合大类无自身关键词，由计数规则自动触发。通常对应多香味礼盒/套装蜡烛。

## 三、搜索策略（所有有香商品都搜索）

### 优先级

```
① 官网/品牌页     site:brand.com product_name
       ↓ 找不到
② Amazon 页面     site:amazon.com "product_name"
       ↓ 找不到  
③ 香水评测站      site:fragrantica.com OR site:nosetime.com product_name
       ↓ 找不到
④ 通用 Bing       "product_name" candle scent notes fragrance
```

### 搜索→提取流程

```
搜索结果文本
    ↓
清洗（同 1.2 排除规则）
    ↓
关键词匹配（同第二章分类体系）
    ↓
提取新发现的关键词 → 加入二级香调
    ↓
如有新香族命中 → 扩展一级分类
```

## 四、输出格式

每款商品输出：

| 字段 | 说明 |
|------|------|
| 商品名 | 原始名称 |
| 无香判定 | 是/否 |
| 一级香族 | 命中的香族列表（如：花香, 果香） |
| 二级香调 | 命中的具体香调（如：lavender, vanilla, sandalwood） |
| 一级来源 | 关键词匹配 / 在线搜索 |
| 搜索URL | 在线搜索时记录来源 URL |
